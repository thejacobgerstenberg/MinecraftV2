World select

Listbox of world cards. Selection = 2px knotlight LUMINANCE frame (survives all three colorblind sims — never a hue-only recolor). Keyboard: arrows move + select, Enter plays, Delete opens the destructive-confirm modal (explicit Cancel — no dead ends), Escape / Back emits lf-back. Double-click a card to play. The Play / Edit / Delete row is a mouse affordance revealed on hover or selection.

World select

Listbox of world cards. Selection = 2px knotlight LUMINANCE frame (survives all three colorblind sims — never a hue-only recolor). Keyboard: Up/Down move + select, Enter plays, E edits, Delete opens the destructive-confirm modal (explicit Cancel — no dead ends), Escape / Back emits lf-back. Right/Left rove within the focused card — card → Play → Edit → Delete (Enter/Space activates, Escape returns to the card) — while the card stays the list's only Tab stop. Double-click a card to play; the action row is revealed on hover, selection, or focus. Cards are role="option" only inside the listbox; standalone cards expose role="group" named by the world.

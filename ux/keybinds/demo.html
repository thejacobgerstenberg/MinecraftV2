Key Bindings — <lf-keybinds>

Simulate lf-options-change (uiScale 1.25) Toggle light / dark

Keyboard path: Tab to any binding, press Enter to start capture, then press the new key (Escape cancels, Backspace clears). Mouse buttons and the wheel are also capturable into keyboard slots. Gamepad capture is a documented polling stub. Assigning a key that is already bound highlights both rows (dashed hem + fray-knot glyph), raises a warning toast, and offers Swap or Unbind & Assign. Changes persist to localStorage "loomfall.bindings" and emit lf-bindings-change.

This demo docks <lf-keybinds> into the ui-kit settings shell. The Done button and Escape emit lf-back (logged in the event log); a capture in progress swallows its own Escape first.
